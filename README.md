# INTERACTIVE VISUALIZATION

## Task 03 – HR Employee Attrition Dashboard

This task focuses on creating an interactive dashboard using **Tableau** to analyze the **HR Employee Attrition** dataset. The dashboard provides meaningful insights into employee attrition by visualizing key HR metrics and enabling interactive filtering for better decision-making.


# Objective

Develop an interactive dashboard that:

- Analyzes employee attrition trends
- Visualizes department-wise attrition
- Compares monthly income across departments
- Examines attrition by job role and gender
- Identifies factors related to employee attrition
- Provides interactive filtering for better analysis

---

# Tools Used

- Tableau
- HR Employee Attrition Dataset

---

# Dataset

**Dataset:** HR Employee Attrition

The dataset includes:

- Employee Number
- Department
- Job Role
- Gender
- Monthly Income
- Job Satisfaction
- Overtime
- Attrition Status

---

# Dashboard Features

- Department-wise Attrition Analysis
- Attrition by Job Role
- Monthly Income by Department
- Attrition by Gender
- Overtime Analysis
- Monthly Income vs Job Satisfaction
- Interactive Dashboard Filters



# Key Insights

- Research & Development and Sales departments have the highest employee attrition.
- Sales Executives and Laboratory Technicians experience higher attrition than other job roles.
- Overtime appears to be associated with increased employee attrition.
- Monthly income and job satisfaction provide useful insights into employee retention.
- Interactive filters allow users to explore attrition patterns across different employee groups.
